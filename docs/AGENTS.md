# Documentation rules

- Use the location table in [README.md](./README.md). Do not add new top-level documents without a reason.
- Tickets and specs go in GitHub Issues, not in `docs/`.
- When a decision is accepted, add an ADR, update `adr/README.md`, and remove it from `open-decisions.md`.
- Never rewrite an accepted ADR or a dated audit. Supersede it with a new file.
- Keep `PLAN.md` status current when phases or roadmap items change.
- Only record what was verified as verified. Say what was not tested.
