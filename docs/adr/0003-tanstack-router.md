# TanStack Router for the web client

We use TanStack Router rather than React Router. A media library is mostly URL state (search, sort, filters, page), and TanStack Router validates that state with Zod and types it end to end. In a spike, an invalid `sort` value failed at compile time.

## Consequences

`routeTree.gen.ts` is generated by the build. The library is less widely known than React Router.
