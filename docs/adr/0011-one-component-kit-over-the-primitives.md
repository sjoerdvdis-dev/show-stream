# One component kit, and primitives only through it

Every shadcn base component is installed in `packages/ui/src/components`, but only the component kit in `packages/ui/src/kit` imports them, and apps import the kit only. The kit is one folder, built the way shadcn's blocks are, that takes in the earlier `packages/ui/src/patterns`: from a sidebar and a header to `MediaMeta` and `Timestamp`, each part exists once, and a part that appears twice is a kit component. A lint rule enforces both import boundaries. This keeps every page consistent and every client on the same parts, keeps unused primitives out of the bundle, and leaves the primitives close to upstream so that `shadcn add --diff` still works. The cost is that a screen needing something new waits for the kit to gain it, and that a primitive gets its tests and preview only when the kit first uses it. See `docs/PLAN.md` Phase 4 and section 9.5.1.
